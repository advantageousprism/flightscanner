# AeroGuard — Autonomous Flight Price Tracker & Post-Purchase Rebooking Engine

## Quick Start (PyCharm or Terminal)
1. Clone this repository in PyCharm: **File → New → Project from Version Control** -> `https://github.com/advantageousprism/flightscanner.git`
2. Save the main component from the editor into `src/App.jsx`.
3. Install dependencies and launch:
```bash
npm install
npm run dev
```
